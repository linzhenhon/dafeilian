# 动作触发与衔接（0.1.18）

## 当前自定义角色

公开源码默认加载 `assets/pet-manifest-custom.json` 和由 `scripts/generate_public_assets.py` 生成的原创机器人透明精灵图。`motionProfiles` 控制呼吸、思索、工作和等待等动作。Windows / Linux Qt Helper 拖拽时按最近的鼠标移动识别八个方向：向上显示背面、向下显示正面，左右与斜向显示侧面并镜像和倾斜；松开后切回正面图做落地回弹。macOS Helper 和页面角落的小宠物仍使用飞行图。启用“减少动态”后停止悬浮摆动，但拖拽方向仍会切换。私人角色原图与渲染源图仅在本机忽略目录中保存，不进入公开仓库。

Qt Helper 点击头部会显示眯眼缩头的摸头反应，点击腹部会后仰吃惊，点击两侧翅鞘会回头看；双击角色触发摸头。每个姿态播放约 0.8 秒并回到当前任务状态，点击冷却为 1.2 秒。点击空白气泡或透明区域不触发。开启“减少动态”时仍显示对应静态反应姿态，停用摇摆。

以下规则和时长记录的是保留在 `assets/pet-manifest.json` 的原版逐帧角色。

原生 Windows / Linux Qt Helper、macOS Helper 使用同一份动作清单。
页面内角色同步任务状态与完成提示，不播放随机待机动作和鼠标互动。

| 动作 | 触发与频率 | 播放和衔接 |
| --- | --- | --- |
| 待机呼吸 | 空闲或断开连接时 | 10.122 秒循环；断开时由状态气泡说明连接问题 |
| 思考冒泡 | DSH 回合开始、工具结束后继续整理 | 10.122 秒循环；重复同类事件不会重播起点 |
| 忙碌点按 / 张望 / 清点归档 | 工具调用；根据搜索、编辑、命令、测试活动选择 | 10.122 秒循环；更新任务时立即切换到最新状态 |
| 等待批准或回答 | DSH 等待用户时 | 使用上游带沙漏的张望动作；保持循环，直到等待解除 |
| 雀跃庆祝 | 一轮任务完成时 | 完整播放 10.122 秒，含起势与回到站姿；重复完成提示合并，新的任务可立即打断 |
| 叹气冒汗 | 工具临时失败或回合出错 | 4.956 秒播一次；临时失败返回当前工作，持续错误保持末帧，直到状态改变 |
| 悬空拖拽 | 鼠标拖动角色时 | 只循环源视频 2～8 秒的悬空段，避免拖到一半自行落地 |
| 松手落地 | 拖拽结束时 | 接源视频 8 秒至结束的 49 帧，完整播 2.058 秒，再回最新任务状态；重新拖拽立即接管 |
| 迎接文件 / 接住文件 | 从资源管理器拖动本地文件到桌宠或任务输入窗口时 | 悬停时双手张开准备接；松开后双手抱住蓝色文件夹、点头，约 0.9 秒返回最新任务状态。文件加入附件列表，等待用户点“发送” |
| 摸头 / 戳角色 / 点尾巴 | 点击不同部位；双击对应摸头 | 使用完整源视频，10.122 秒播一次；动作期间不接受另一个点击动作，状态打断后仍保留 1.2 秒点击冷却 |
| 伸懒腰 / 打哈欠 / 吃 Token | 仅空闲时随机选择，不连续重复上一段 | 每段完整播放 10.122 秒，再开始休息计时；安静 45～90 秒、标准 25～45 秒、活泼 12～22 秒 |

## 优先级与绘制

- 拖拽和落地保护当前鼠标动作；DSH 状态持续更新，落地后显示最新状态。
- 工作、等待和错误消息立即打断待机／点击动作；完成提示接管装饰动作。
- 点击不插入正在播放的完成／错误提示；待机动作只在空闲且没有其他动作时触发。
- 同一视频的连续帧直接绘制，不叠加呼吸缩放、摇摆或逐帧淡化。不同动作之间使用 100 毫秒淡化；拖拽相关切换直接绘制。
- 完成和错误提醒不再抖动整个窗口。气泡、余额和任务列表变化保留角色坐标；Qt 在屏幕顶部空间不足时将气泡放到角色下方。
- 原版逐帧角色在“减少动态”时固定姿势；当前自定义角色仍保留点击反应的静态姿态。完成提示按消息原始时长显示；状态与余额继续更新。

## 素材核对与复现

本次核对时，桌面端安装的 0.1.15 与仓库内原有 2,600 帧逐一校验一致。
运行清单只引用 `assets/pet/` 的上游角色帧，没有引用 `legacy/` 的旧角色图。
不自然的切换来自中段裁切、逐帧淡化、额外程序化摇摆，以及计时器拼接的眩晕／生气链。

0.1.16 清单共 16 段、3,444 帧，统一画布 412 × 344。
素材来自 [dsh-pet 固定版本](https://github.com/PC2005-cloud/dsh-pet/tree/549fff2ea33c2acfb16612c76912c6137da4a758/dsh-pet/assets/webm)，
恢复的是视频已有的起势、落地和收尾帧。清单记录每个源视频的 SHA-256、帧范围和共同裁切窗口；上游 MIT 许可证随包分发。

```powershell
python scripts/import_dshpet_webm.py --source <该版本的dsh-pet/assets/webm> --ffmpeg <ffmpeg目录> --out .
npm test
npm run test:python
```

动画时长按运行时 42 毫秒／帧计算。源视频由 AI 生成，不同视频的细节和角色比例仍有少量变化；修复播放规则不会重绘这些源图。
