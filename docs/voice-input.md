# 桌宠语音输入

先在 DSH 打开目标对话。桌宠气泡底部是一体式任务输入区：上方输入文字或查看已选文件，下方左侧用加号添加文件，右侧依次是录音、通话和发送。按钮悬停时会显示用途。支持以下方式：

- **键盘**：输入文字后按回车或点纸飞机图标发送；Shift+回车可手动换行。录音转写的长句会自动换行，连续识别的句子分行显示。输入框会随内容增高，超过可见高度后可在框内滚动查看全文。
- **文件**：点输入区左下角的加号，或将资源管理器里的文件拖到桌宠、气泡或任务输入窗口中，最多可选 8 个本地文件。输入区内会显示已选文件名，超过三项可滚动查看；任务输入窗口中也会显示文件列表。双击文件名可移除，右键列表或加号按钮可移除或清空。拖入时桌宠伸手迎接，放下后做接住动作；放下不会自动发送。可只发文件，也可附上文字。文件先上传到当前 DSH 对话，再随任务一起提交；发送失败时选择会保留供重试。
- **录音**：点麦克风图标开始；停顿后识别出的文字会填入输入框。点红色停止图标结束后，如有片段仍在处理，桌宠会持续显示“正在识别录音”和等待时间；结果返回后检查文字再发送。未听清时会显示明确提示。
- **通话**：点电话图标开始持续监听；每次说完并停顿约 0.8 秒，会把这句话排队发到当前对话。DSH 回复后，桌宠用 Windows 中文系统语音朗读。点蓝色挂断图标结束。右键菜单也有对应入口。

通话气泡中有可滚动的文字区：每句话识别完成后显示“我：…”，DSH 的回复到达后显示“大哥：…”。文字区保留本次通话的最近 40 条消息，开始下一次通话时清空。正在说话时仍先显示音量和识别阶段，文字会在该句识别完成后出现。

录音时桌宠会换成持麦倾听的形象，显示红色录音标记和录音时长；通话时会换成拿手机交谈的形象，显示蓝色通话标记和通话时长。即使平时隐藏了气泡，这两个状态仍会显示状态卡片和对应的“停录”或“挂断”按钮。拖动桌宠时暂时显示飞行动作，放开后恢复当前语音形象。

录音和通话期间，气泡中的音量条会根据麦克风输入实时跳动，并显示“加载识别模型”“正在聆听”“正在说话”“正在识别”等阶段；通话还会显示“正在发送任务”“正在朗读回复”。每句话识别完成后，气泡短暂显示识别文字。文字识别在停顿后进行，音量条则随录音即时变化。朗读回复时麦克风暂停，蓝色音量条表示播放动画。

首次识别需要加载本地 Whisper 模型；后续每句话复用同一工作进程。录音按最长约 20 秒的片段切分，可以一直通话，原始音频片段在识别完成后删除。朗读时暂停麦克风，避免把桌宠自己的声音再次发送。只有语音通话模式会自动发送识别文字。

识别出的中文会在填入输入框或发送任务前转为简体字。Windows 使用系统自带的简繁转换；Linux 和 macOS 可在语音识别 Python 环境安装 `opencc-python-reimplemented` 来启用同样的转换。

本地识别需要一个装有 `torch`、`transformers`、`soundfile`、`scipy` 和 `opencc-python-reimplemented` 的 Python 环境，以及已下载的 `openai/whisper-base` 模型。在插件设置的“语音输入设置”中填写 Python 路径；如果模型不在默认缓存中，再填写模型路径或 Hugging Face 缓存目录。语音识别不调用云端接口。没有可用麦克风或模型时，桌宠会显示具体错误，键盘输入仍可使用。

录音会优先使用 16 kHz 单声道；麦克风不原生支持该格式时，会自动采用设备首选的采样率和声道数，并在本机转换后再识别。如果仍提示无法开始录音，请在系统隐私设置中允许 Python 或 `dsh-dafeiyu-helper` 使用麦克风，并确认麦克风没有被其他程序独占。

“识别服务”可以切换为 **DSH 内置 SenseVoice**。此时桌宠把录到的 WAV 交给 DSH 的语音识别服务，识别出的文字继续填入输入框，或在通话模式发送到当前对话。首次使用要在 DSH 的官方“语音输入”组件中准备本地模型。DSH 语音服务只负责转文字；当前对话中的 AI 接收转写文字，不直接接收麦克风音频。切回“插件本地 Whisper”即可继续使用原来的 Python 模型。

插件设置的“提示音版本”里可试听三套公开版合成音效，包括睡觉、闹钟和待办提醒。公开仓库不包含用户录音、男声或女声配音。当前生活提醒仅提供试听，提醒时间和触发条件尚未设置，因此不会自动播放。

“提示音版本”还可选“自定义”，分别为对话完成、工具出错、等待审批、睡觉、闹钟和待办六种场景上传音频。设置页可读取 WAV、MP3 或 M4A，并在浏览器中转成最长 30 秒的单声道 WAV 后保存到本机用户数据目录 `dsh-dafeiyu/custom-sounds`；文件不会写进插件安装目录。每一项都可试听或恢复原版。选择自定义后，未上传的场景沿用原版提示音。前三种场景按原有提示音开关播放；后三种生活提醒仍需以后设置提醒时间才会自动播放。

首次加载本地 Whisper 模型可能需要数十秒，气泡会显示“加载识别模型”和提示；在插件设置开启“后台预载语音识别模型”后，DSH 启动时会提前加载并保留模型，以减少首次录音或通话等待，但会持续占用更多内存。加载失败会显示具体错误。
